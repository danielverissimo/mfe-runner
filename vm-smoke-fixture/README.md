# VM smoke workspace

Workspace genérica e sem dependências externas para validar o binário
empacotado do MFE Runner em Windows e Linux. Ela é gerada no host macOS e
somente copiada e executada nas VMs; nenhum install ou build é necessário
nelas.

- Aplicação principal: porta 4590
- Serviço local: porta 4591
- Runtime: Node 24.15.0
